SITE SCIENTIFIQUE PERSONNEL - SEBASTIEN GUILTAT - V2.1

Contenu :
- index.html : page principale
- assets/site.css : feuille de style
- assets/img/ : portrait
- assets/pdf/ : versions auteur et CV scientifique PDF

Mise en ligne GitHub Pages :
1. Créer un dépôt GitHub (ex. sebastien-guiltat)
2. Déposer tout le CONTENU de ce dossier à la racine du dépôt : index.html + assets + README.txt
3. Dans GitHub : Settings > Pages
4. Source : Deploy from a branch
5. Branch : main / root
6. Enregistrer.

Pour modifier ensuite :
- éditer index.html directement dans GitHub puis Commit changes ;
- remplacer un PDF dans assets/pdf/ en conservant le même nom ;
- ou modifier assets/site.css pour l'apparence.
